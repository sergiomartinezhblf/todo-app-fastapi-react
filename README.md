# Todo App

Aplicación web para gestionar tareas (crear, editar y eliminar).

---

## 🚀 Demo

Frontend: https://todo-app-fastapi-react-xi.vercel.app/
Backend: https://todo-backend-0oc6.onrender.com  

---

## 🛠️ Tecnologías

- React + TypeScript
- FastAPI (Python)
- Vite
- Bootstrap
- Vercel (frontend)
- Render (backend)

---

## ⚙️ Instalación

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --reload

### Frontend

```bash
cd frontend
npm install
npm run dev
